About This App

Beta Version 1.0

This application is a Psychiatric Decision-Support framework utilizing AWS Bedrock and HuggingFace pipelines. It filters telehealth sessions using RoBERTa sentiment analysis and performs deep forensic audits using Claude 4.6 Sonnet based on the Interpersonal Theory of Suicide (IPTS) and Columbia-Suicide Severity Rating Scale (C-SSRS).

How to Use:

  • Upload raw .wav telehealth audio files via the Add Patient portal.
  • The AWS pipeline will automatically diarize the audio and run the dual-layer NLP triage.
  • Review the AI-generated clinical logic and acknowledge high-risk flags in the Patient Details pane.
